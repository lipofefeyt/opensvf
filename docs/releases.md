# Releases

opensvf releases are tagged on GitHub and published on PyPI:

- [GitHub releases](https://github.com/lipofefeyt/opensvf/releases), with the
  notes of every version; from 1.4.0 each release also carries the data pack
  as PDFs: the Architecture Description (ADD), the Software Validation
  Specification (SVS) and the Interface Control Document (ICD), built from
  this site's pages of the same version
- [opensvf on PyPI](https://pypi.org/project/opensvf/)

Each release is tested in CI against the openobsw release pinned in
[`.openobsw-version`](https://github.com/lipofefeyt/opensvf/blob/main/.openobsw-version).
The [openobsw documentation](https://openobsw.readthedocs.io/) describes the
flight software side.

A changelog is added with release 1.4.0.
